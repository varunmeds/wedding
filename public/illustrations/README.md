# Illustrations

Drop your generated cartoon PNGs here with these exact names. Until a file
exists, its slot on the site simply stays empty (no broken image).

| Filename            | Where it appears           |
| ------------------- | -------------------------- |
| `oorkuduva.png`     | Oorkuduva ceremony card    |
| `muhurtha.png`      | Muhurtha ceremony card     |
| `ganga-pooje.png`   | Ganga Pooje ceremony card  |

**Tips for best results**

- Export as **PNG with a transparent background**; the cards are dark, so a
  white box around the image will look out of place.
- Roughly **square** works best for the ceremony icons.
- Keep a **consistent style** across all three so they look like a set.

To change a filename or path, edit `image:` fields in `src/content.js`.
